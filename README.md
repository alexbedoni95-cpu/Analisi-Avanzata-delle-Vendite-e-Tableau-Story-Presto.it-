# Analisi-Avanzata-delle-Vendite-e-Tableau-Story-Presto.it-
Stack:Tableau, Data Visualization, Data Storytelling, Excel/SQL
Dataset utilizzato: Presto.
Tableau Story completa per l'analisi delle performance commerciali dell'e-commerce Presto.it (2014-2017). Presenta dashboard interattive su trend temporale delle vendite, segmentazione per tipo di cliente, redditività per categorie, top prodotti e analisi geografica con un focus approfondito sul Nord Italia, Lombardia ed Emilia-Romagna.
